# Helper

Repositorio de utilidades y herramientas experimentales de desarrollo propio. Este espacio recopila scripts, prototipos y desarrollos funcionales pero sin refinar, concebidos para resolver problemas específicos, automatizar tareas o servir de banco de pruebas metodológico.

El código aquí albergado se presenta tal cual, con el objetivo de servir como base de estudio, prueba o soporte operativo en distintos ámbitos técnicos.

---

## Estructura del Repositorio y Módulos

El repositorio se divide en diferentes directorios según el propósito de cada herramienta. Cada módulo cuenta con su propia documentación técnica detallada en su respectivo `README.md`.

| Módulo | Estado | Descripción técnica | Enlace a Documentación |
| :--- | :--- | :--- | :--- |
| **`Bocetos`** | Experimental / Sin refinar | Generador de bocetos y estructuras proporcionales basado en parámetros y medidas corporales. | [Ver README](./Bocetos/README.md) |
| **`Password`** | Experimental / Sin refinar | Utilidades de análisis de claves que incluyen un diccionario masivo (+10k palabras) orientado a auditorías de seguridad, junto a simuladores de fuerza bruta y ataques por diccionario. | [Ver README](./Password/README.md) |
| **`registro_de_ventas`** | Experimental / Sin refinar | Herramienta orientada al registro, control y procesamiento de transacciones comerciales. | [Ver README](./registro_de_ventas/README.md) |
